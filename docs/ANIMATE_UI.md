# Animate UI

本站使用个人主页主分支 `e0cab69` 中的 Animate UI 组件。上游版本为
[animate-ui / efeb96f](https://github.com/imskyleen/animate-ui/tree/efeb96ffd7a3b7a4868667e4ac3c346620fb3044)，
保留[原许可证](../components/animate-ui/LICENSE.md)。标题使用 SplittingText，章节使用 Fade，首页入口使用 FlipButton，笔记使用 Accordion。
动效遵循系统的减少动态效果偏好。

按钮、折叠项和焦点反馈参考 [Animate UI 的交互组件](https://github.com/imskyleen/animate-ui/tree/main/apps/v2/content/docs/primitives/base-ui)。首页机械臂参考 [The Hand](https://github.com/PabloMesquida/the-hand) 的指针跟随原则，关节、夹爪、工件和抓放轨迹由本站 Canvas 代码绘制。页面进退的遮罩方向参考 [Isle & Thorne Collective](https://github.com/codrops/isle-thorne-collective)，在支持跨文档 View Transitions 的浏览器中启用，链接保留原生导航行为。
