# Animate UI

本站使用个人主页主分支 `e0cab69` 中的 Animate UI 组件。上游版本为
[animate-ui / efeb96f](https://github.com/imskyleen/animate-ui/tree/efeb96ffd7a3b7a4868667e4ac3c346620fb3044)，
保留[原许可证](../components/animate-ui/LICENSE.md)。标题使用 SplittingText，章节使用 Fade，
项目筛选使用 Tabs 与 Highlight，首页入口使用 FlipButton，笔记使用 Accordion。
动效遵循系统的减少动态效果偏好。
